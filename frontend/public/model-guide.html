Flux 2 Pro

Best for photoreal stills

T2I

vision:flux 2 pro t2i

Strengths

  • Studio-grade photoreal. Default T2I in V2.
  • Reliable start/end frames before I2V.
  • Cheap versus a video miss.

Watch-outs

  • Not the cheapest Flux 2 SKU.
  • Type and infographics lose to Qwen / Recraft.

Use for

  • Listing hero stills
  • Start frame for I2V
  • Photoreal product plates

  • Prompt fishing

FLUX 3

Best all-round T2V with draft→enhance

T2V

vision:flux 3 t2v

Strengths

  • 5–20s, native audio.
  • Draft then enhance to cut cost.
  • BFL on fal — V2 already wired.

Watch-outs

  • Not 30s (that's Seedance).
  • Extend is a separate SKU and costs more than the I2V rate.

Use for

  • Hero prompt-to-clip
  • Audio-on social videos

Seedance 2.5

Best for long single-shot T2V (up to 30s)

T2V

vision:seedance 2.5 t2v

  • Native 4–30s with audio.
  • 480p/720p/1080p.
  • Strong motion.

Watch-outs

  • Photoreal people can trip the face filter on related R2V.
  • Pricey at 1080p.

Use for

  • Walkthrough-length clips
  • Unbroken camera moves
